# Vanty-Web 🧠✨

Plataforma web oficial y sistema de gestión clínica para centros de terapia y neuropsicología, desarrollada para **Capyaba** y optimizada para la gestión de terapias de Análisis Conductual Aplicado (ABA).

🔗 **Sitio Web en Producción:** [www.terapiassanti.com](https://www.terapiassanti.com/)

---

## 🚀 Stack Tecnológico

Este proyecto está construido con tecnologías modernas de desarrollo web y bases de datos en la nube:

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
* **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
* **Base de Datos & Backend:** [Supabase](https://supabase.com/) (PostgreSQL & PL/pgSQL)
